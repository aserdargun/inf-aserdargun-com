# Product

Infographics follows Capture → Organize → Resurface → Recall → Learn. Owner routes are Today, Add, Inbox, Library, infographic detail, Surprise, Review, and Settings. Capture supports file selection, drag/drop, and clipboard images; optional source metadata stays private. The first category moves an item from Inbox to Library. Surprise deliberately records a seen event. Review stores calculated Again/Hard/Good/Easy outcomes as immutable history.

View Mode is anonymous and intentionally sparse: public-safe title, public image/thumbnail, and publication date only. It never contains notes, source data, tags, categories, favorites, review or seen history, statistics, or Drive credentials.
