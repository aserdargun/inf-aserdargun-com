# Roadmap

## MVP now

Manual capture and Drive Inbox sync, deterministic search, categories/tags, public View Mode, weighted Surprise, simple persisted review intervals, PWA read caching, and inventory/export guidance.

## Deliberately later

Manual recall prompts; an opt-in deterministic SM-2-style scheduler migration that never rewrites history; transparent review-based statistics; and gamification that rewards recall/review rather than collecting images. Token-authenticated external ingestion is also future work and remains disabled.
